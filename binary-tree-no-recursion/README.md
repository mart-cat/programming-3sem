# Бинарное дерево без рекурсии (Binary Tree)

Решение задачи «Бинарное дерево» на Python без рекурсии (в ширину). Вариант 8.

## Условие

Создать функцию `gen_bin_tree`, которая строит полное бинарное дерево
в виде словаря с ключами `value`, `left`, `right`.

Вариант 8:
- `root = 8`
- `height = 4`
- `left_leaf = lambda x: x + x / 2`
- `right_leaf = lambda x: x ** 2`

## Пример

При `gen_bin_tree(1, 8)`:

```python
{
    'value': 8,
    'left': {'value': 12.0, 'left': None, 'right': None},
    'right': {'value': 64, 'left': None, 'right': None}
}
```

При `height=0` дерево состоит только из корня.

## Решение

Функция находится в `app.py`. Дерево строится в цикле `while` с помощью
очереди `deque`: на каждом шаге из очереди извлекается узел и, если он
ещё не на последнем уровне, к нему добавляются два потомка, значения
которых вычисляются переданными `left_leaf` и `right_leaf`.

Рекурсия не используется — обход итеративный (BFS), поэтому глубина
дерева ограничена только памятью, а не лимитом рекурсии Python.

Дерево хранится в `dict`. Для хранения дерева также можно использовать
`list`, `tuple` и `collections.namedtuple`.

### Реализациия

- `height == 0` → дерево из одного корневого узла (`left = right = None`).
- `height < 0` → поднимается `ValueError`.
- Каждый узел — словарь `{"value": ..., "left": ..., "right": ...}`;
  у листьев `left` и `right` равны `None`.
- Значения по умолчанию для `height`, `root`, `left_leaf` и `right_leaf`
  заданы в сигнатуре функции и соответствуют варианту 8, поэтому вызов
  `gen_bin_tree()` без аргументов работает.
