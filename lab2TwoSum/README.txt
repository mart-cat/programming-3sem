# Сумма двух (Two Sum)

Решение классической задачи «Сумма двух» на Python.

## Условие

Дан массив целых чисел nums и целое число target.
Нужно вернуть индексы двух элементов массива, которые в сумме дают target.

- У каждого набора может не быть решения или быть только одно.
- Один и тот же элемент нельзя использовать дважды.
- Порядок индексов в ответе не важен.

## Примеры

| Вход                                  | Выход    |
|---------------------------------------|----------|
| nums = [2, 7, 11, 15], target = 9     | [0, 1]   |
| nums = [3, 2, 4],      target = 6     | [1, 2]   |
| nums = [3, 3],         target = 6     | [0, 1]   |

## Решение

Файл twosum.py содержит функцию add(nums, target).

Используется хеш-таблица (словарь) для хранения уже просмотренных чисел:

    def add(nums, target):
        seen = {}
        for i, num in enumerate(nums):
            need = target - num
            if need in seen:
                return [seen[need], i]
            seen[num] = i
        return []
